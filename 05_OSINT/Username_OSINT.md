# What It Is

Username OSINT is checking where a specific, already-public username or handle appears across platforms, using publicly visible profile information only — for example, confirming whether the same handle is consistently used across multiple public platforms as part of verifying an identity claim.

# Why It Matters

Usernames are often reused across platforms, which can help verify (or contradict) a claimed identity using only public, already-consented-to-be-visible information.

# When To Use It

When verifying whether an account claiming a certain identity is consistent with that identity's other public presence — not for locating or profiling private individuals without a legitimate verification purpose.

# How To Use It Safely

- Only look at information the account holder has made public — do not attempt to access private profiles, private messages, or non-public data.
- Use this for verification (does the public record support a claim?), not for building a profile of someone unrelated to a specific, legitimate question.
- Be aware that username reuse is circumstantial evidence, not proof of identity — the same handle can be used by unrelated people.
- This is not a technique for locating, contacting, or targeting private individuals. CORE does not cover real-world targeting workflows — see [[CORE_Principles]].

# Common Mistakes

- Treating a shared username across platforms as definitive proof of a single identity, without other corroborating evidence.
- Conflating "public OSINT verification" with "investigating a private person" — the former verifies a specific claim; the latter is out of CORE's scope.
- Not considering that impersonation accounts commonly reuse a target's real handle deliberately.
