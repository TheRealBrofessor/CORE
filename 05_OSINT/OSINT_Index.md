# OSINT Index

OSINT (Open Source Intelligence) in CORE means using publicly available information to verify claims — not to target, surveil, or investigate real individuals. This area focuses on search technique and, critically, on judging source reliability and verifying findings.

- [[Search_Operators]] — getting precise results from search engines.

- [[Domain_OSINT]] — passively researching a domain's public footprint.
- [[Username_OSINT]] — passively researching a public username's footprint.
- [[Image_OSINT]] — verifying an image's origin and context.
- [[Verification_Methods]] — a general framework for verifying a claim before trusting it.
