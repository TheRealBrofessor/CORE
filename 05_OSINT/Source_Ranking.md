# What It Is

Source ranking is judging how much weight to give a piece of information based on where it came from: primary sources (original documents, direct statements, official records) generally outrank secondary sources (news coverage, summaries), which outrank tertiary or unverified sources (social media posts, forums, anonymous claims).

# Why It Matters

Not all information is equally trustworthy, and OSINT work is only as good as the judgment applied to sources. This is the core skill that separates useful verification from spreading unverified claims.

# When To Use It

Every time you're evaluating a claim — before citing it, acting on it, or including it in a CORE note's Sources section.

# How To Use It Safely

- Ask: is this a primary source, or a summary of one? Try to trace claims back to their origin.
- Check for corroboration — does more than one independent source agree?
- Consider the source's incentive — is there a reason this source might exaggerate, omit, or misrepresent?
- Note the date — even a reliable source can be outdated.

# Common Mistakes

- Trusting a source because it's popular or high-ranking in search results, rather than because it's verifiably accurate.
- Treating "I found it on the internet" as sufficient sourcing.
- Circular sourcing — multiple outlets that all cite the same single unverified original claim, mistaken for independent corroboration.
