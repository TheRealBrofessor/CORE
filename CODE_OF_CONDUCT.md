# Code of Conduct

## Our Standard

CORE is a public educational project. Contributors and participants are expected to:

- Be respectful and constructive in issues, pull requests, and discussions.
- Focus criticism on content, not people.
- Accept that content may be revised, corrected, or rejected if it falls outside CORE's defensive-only educational scope.
- Disclose uncertainty honestly rather than asserting unverified claims as fact.

## Not Acceptable

- Harassment, personal attacks, or discriminatory language.
- Submitting offensive-security material, malware, or unauthorized-access content disguised as educational content.
- Submitting content about real individuals, real incidents, or real targeting without a legitimate, clearly-scoped educational purpose.
- Deliberately misleading or unsourced technical claims presented as fact.

## Scope

This Code of Conduct applies to all CORE spaces: issues, pull requests, discussions, and any other official project communication channel.

## Enforcement

Maintainers may edit, close, or reject any contribution or interaction that violates this Code of Conduct or CORE's defensive-only scope, and may block repeat violators from the repository.

## Reporting

If you experience or witness unacceptable behavior, open a GitHub issue marked appropriately, or contact a maintainer directly through the repository.
