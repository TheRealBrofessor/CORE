# Cloud DevOps Path

An ordered path focused on version control, containers, pipelines, and server operation.

1. [[Git]] — version control fundamentals.
2. [[GitHub]] — collaboration around a Git repository, then run the [[Repo_Audit_Checklist]] on a repo you maintain.
3. [[Docker]] — packaging and running applications in containers.
4. [[CI_CD]] — automated pipelines, conceptually, even before you set one up.
5. [[VPS_Basics]] — apply it all to a real server, then run [[New_Linux_Box_Checklist]] and [[Basic_Hardening_Checklist]].
