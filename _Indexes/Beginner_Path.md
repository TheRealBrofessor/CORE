# Beginner Path

An ordered path for someone with little to no prior technical background.

1. [[Welcome]] and [[How_To_Use_CORE]] — orient yourself in the vault.
2. [[Computer_Science]] — the basic mental model of what a computer does.
3. [[Command_Line]] and [[Filesystems]] — the two foundational operating skills.
4. [[Terminal]] — apply the command line specifically on Linux.
5. [[Permissions]] — understand access control, then do the [[Linux_File_Permissions_Lab]].
6. [[Networking_Basics]] — the smallest useful model of a network.
7. [[Security_Basics]] — the core frame (CIA triad) for everything defensive later.
8. [[Git]] and [[GitHub]] — version control, useful for any technical work going forward.
9. [[Prompting]] — how to get useful results from AI tools, since you'll likely use one throughout the rest of your learning.

## Where To Go Next

Once comfortable here, pick a focused track: [[Linux_Path]], [[Blue_Team_Path]], [[OSINT_Path]], [[AI_Tooling_Path]], or [[Cloud_DevOps_Path]].
