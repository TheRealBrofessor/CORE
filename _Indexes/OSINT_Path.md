# OSINT Path

An ordered path focused on OSINT verification technique — finding and judging public information, not investigating private individuals.

1. [[Search_Operators]] — precise queries.
2. [[Source_Ranking]] — judging trust before you judge content.
3. [[Verification_Methods]] — the general verification framework everything else applies.
4. [[Domain_OSINT]] — passive domain/infrastructure research.
5. [[Username_OSINT]] — passive public-footprint checks.
6. [[Image_OSINT]] — verifying an image's origin and context.
7. [[Source_Verification_Checklist]] and the [[Source_Verification_Lab]] — apply everything end-to-end.
