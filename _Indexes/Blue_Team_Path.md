# Blue Team Path

An ordered path focused on defensive security (blue team). Assumes [[Linux_Path]] and [[Networking_Index]] basics.

1. [[Security_Basics]] — the CIA triad frame.
2. [[Threat_Modeling]] — think before you defend.
3. [[Hardening]] — reduce attack surface, then run [[New_Linux_Box_Checklist]] and [[Basic_Hardening_Checklist]].
4. [[Logging_Monitoring]] — see what's happening, then complete the [[Log_Review_Lab]].
5. [[Packet_Capture]] — observe network traffic directly, then complete the [[Packet_Capture_Reading_Lab]].
6. [[Suspicious_Process_Check]] and [[Network_Triage]] — practice triage playbooks.
7. [[Incident_Response]] — the full structured process.
8. [[Forensics_Basics]] — evidence handling at a conceptual level.
9. [[Blue_Team_Playbooks]] — see how all the playbooks connect.
