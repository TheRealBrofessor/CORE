# Welcome

CORE — Community Obsidian Resource for Education — is a Markdown-first, Obsidian-compatible vault for learning computer science, Linux, networking, defensive cybersecurity, OSINT verification, cloud/DevOps, Git/GitHub, and AI coding tools.

## What To Do First

1. Read [[How_To_Use_CORE]] to understand how the vault is organized.
2. Skim [[CORE_Principles]] to understand the ground rules content in this vault follows.
3. Pick a starting point:
   - New to computers/Linux entirely: start at [[Computer_Science]] in `01_Foundations`.
   - Comfortable with basics, want structure: go to the [[Beginner_Path]] in `_Indexes`.
   - Know what you want (Linux, networking, blue team, OSINT, AI tooling, cloud): jump straight to that subject's `*_Index.md` file.
4. Check the [[Master_Index]] any time you want the full map of the vault.

## How the Vault Is Organized

- `01_Foundations` through `10_Glossary` — numbered subject folders, each with its own index.
- `08_Labs` and `09_Playbooks` — hands-on, safe, defensive-only practice material.
- `_Indexes` — the Master Index plus curated reading paths for specific goals.
- `_Templates` — copyable templates for adding new notes, labs, playbooks, and Learning Trails.
- `_Learning_Trails` — real questions learners had, and the path they took through CORE to answer them.

## What This Vault Expects From You

CORE is honest about uncertainty. Notes mark `status: draft` until reviewed, cite sources where possible, and separate verified fact from interpretation. If something in CORE looks wrong, outdated, or unsourced, see [CONTRIBUTING.md](../CONTRIBUTING.md) for how to fix it.
