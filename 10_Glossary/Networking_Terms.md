# Networking Terms

- **IP address** — a numeric address identifying a device on a network. See [[TCP_IP]].
- **Port** — a numbered endpoint on a device that identifies a specific service/connection.
- **TCP** — a connection-oriented, reliable transport protocol. See [[TCP_IP]].
- **UDP** — a connectionless, best-effort transport protocol.
- **DNS** — the system that translates domain names into IP addresses. See [[DNS]].
- **HTTP/HTTPS** — the request/response protocol of the web; HTTPS adds TLS encryption. See [[HTTP]].
- **VPN** — an encrypted tunnel between a device and a server, used to protect traffic in transit. See [[VPNs]].
- **Firewall** — a system that allows or blocks traffic based on rules (typically IP, port, protocol).
- **Packet** — the basic unit of data transmitted over a network. See [[Packet_Capture]].
- **Latency** — the time delay for data to travel from source to destination.
