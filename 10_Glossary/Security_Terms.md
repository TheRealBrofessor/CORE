# Security Terms

- **CIA triad** — confidentiality, integrity, availability: the three properties information security aims to protect. See [[Security_Basics]].
- **Threat model** — a structured analysis of what you're protecting, from whom, and how. See [[Threat_Modeling]].
- **Hardening** — reducing a system's attack surface. See [[Hardening]].
- **Incident** — a suspected or confirmed security event requiring response. See [[Incident_Response]].
- **Chain of custody** — a documented record of who handled evidence, when, and why. See [[Forensics_Basics]].
- **Least privilege** — granting only the minimum access needed to perform a task.
- **Attack surface** — the total set of points where an unauthorized user could try to interact with a system.
- **IOC (Indicator of Compromise)** — an observable artifact (IP, file hash, log pattern) suggesting a system may be compromised.
- **Blue team** — defenders who protect, detect, and respond, as opposed to offensive "red team" testers (out of scope for CORE). See [[Blue_Team_Playbooks]].
