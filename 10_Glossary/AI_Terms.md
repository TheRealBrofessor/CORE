# AI Terms

- **Prompt** — the input given to an AI model to produce a response. See [[Prompting]].
- **Agentic tool** — an AI tool that can take actions (read/write files, run commands) rather than only producing text. See [[Claude_Code]], [[Codex]].
- **Local model** — a model run on your own hardware rather than via a cloud API. See [[Local_AI]].
- **Context window** — the amount of text (measured in tokens) a model can consider at once.
- **Hallucination** — when a model produces confident-sounding but false or unsupported output; a core reason to apply [[Verification_Methods]] to model claims.
- **Token** — a unit of text (roughly a word-piece) that models process and are often billed by.
- **System prompt** — instructions given to a model that shape its behavior for a whole session, distinct from the user's individual messages.
