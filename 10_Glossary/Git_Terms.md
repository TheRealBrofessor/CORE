# Git Terms

- **Commit** — a saved snapshot of changes with a message describing them. See [[Git]].
- **Branch** — a separate, parallel line of commits, typically for in-progress work.
- **Merge** — combining changes from one branch into another.
- **Pull request (PR)** — a proposed set of changes submitted for review before merging, a GitHub feature. See [[GitHub]].
- **Clone** — creating a local copy of a remote repository.
- **Remote** — a reference to a hosted version of a repository (e.g. on GitHub).
- **Force push** — overwriting remote history with local history; can destroy others' commits if used carelessly.
- **.gitignore** — a file listing patterns Git should not track (e.g. build output, secrets).
- **Repository (repo)** — a project tracked by Git, containing its full commit history.
