# Playbooks Index

Playbooks are repeatable checklists for common defensive and operational situations. Unlike labs (which teach a concept hands-on), playbooks are meant to be followed directly when the real situation comes up.

## Playbooks In This Area

- [[New_Linux_Box_Checklist]] — first steps on any freshly provisioned Linux system.
- [[Basic_Hardening_Checklist]] — a general hardening pass for a system you administer.
- [[Suspicious_Process_Check]] — triaging a process that looks wrong.
- [[Network_Triage]] — triaging a network connectivity or traffic problem.
- [[Repo_Audit_Checklist]] — auditing a Git repository's structure and history for problems (as used to prepare this rebuild).
- [[Source_Verification_Checklist]] — verifying a claim before trusting or repeating it.
